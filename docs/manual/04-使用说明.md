# 四、使用说明

这一篇是轻阅其他功能的「怎么做」合集：导入与管理藏书、找书、阅读页的常用工具、AI、PDF 与论文、阅读记录、多端同步、备份、设置与更新，最后是快捷键和常见问题。

---

## 1. 导入书籍

### 支持的格式

| 类型 | 格式 |
|---|---|
| 电子书 | EPUB、MOBI、AZW、AZW3、FB2、FB2.zip（.fbz） |
| 文本 | TXT、HTML / HTM / XHTML、Markdown（.md） |
| 漫画 | CBZ、CBR |
| 版式文档 | PDF、DjVu |

TXT、HTML、Markdown 导入时会自动转换成电子书排版，可以像 EPUB 一样调字号、分章阅读。**不支持** Kindle KFX 和带 DRM 加密的文件，请先用 Calibre 等工具合法转换为 EPUB / AZW3。

### 怎么导入

- **点按钮**：左侧「藏书」→「导入书籍」，可一次选多个文件。
- **拖进来**：把文件直接拖到藏书页，看到「松开导入书籍」后松手。
- **网页链接**：「导入书籍」旁的「更多导入方式」→「网页链接导入」，粘贴书籍下载链接（GitHub 文件页面的链接也能识别），点「下载并导入」。
- **从书源下载**：见第 3 节。
- **桌面版右键打开**：在系统文件管理器里右键书籍文件 →「打开方式」→ LightRead。

导入后会自动读取书名、作者和封面。

## 2. 整理藏书

### 书架

- 顶部搜索框可按**书名 / 作者 / 标签**搜索。
- 排序方式：最近阅读 / 最近添加 / 书名 / 作者。
- 书架标题旁显示藏书数量、累计阅读时长和今日阅读分钟数（点它可进入「阅读记录」）。
- 每张书卡上有快捷操作：置顶、加入书单、从藏书中删除。电脑上鼠标悬停时出现；触屏设备上点卡片上的「更多」按钮。

### 批量管理

点「**管理**」进入多选模式，选中书籍后可以：全选 / 取消全选、**加入书单** / 从书单移除、**置顶**、**设置标签**（多个标签用逗号分隔）、**移至论文** / 移至藏书、删除。

### 书单与分类

- **书单**：用来组织主题阅读、年度计划或待读书目。点「新建书单」创建；在批量管理里把书「加入书单」；点「管理书单」可以重命名或删除。**删除书单不会删除其中的书。**
- **分类（标签）**：在批量管理中给书设置标签后，书架上方会出现分类筛选。「管理分类」里可以重命名或删除分类，删除分类只移除标签，不删书。

### 藏书与论文

「论文」是独立的工作区，有自己的书架、搜索和排序。PDF 放进论文库后会启用翻译、论文 Agent 等精读功能；藏书里的 PDF 保持简洁的阅读界面。在管理模式里可以用「移至论文」「移至藏书」互相移动。

## 3. 找书：书源

左侧「**书源**」页。

### 统一搜书

在最上方的搜索框输入书名或作者，勾选要搜索的来源后点「搜索」：

| 来源 | 内容 |
|---|---|
| 哲学文库 | 马克思主义文库（marxists.org）中英文著作、早期近代哲学文本（Early Modern Texts）、Standard Ebooks 哲学类；随应用附带书目索引，本地即搜，免登录下载 EPUB / PDF |
| 古登堡计划 | 英文等公版书 |
| Internet Archive | 公开图书，按需读取真实的 EPUB / PDF / TXT 下载链接 |
| arXiv | 学术论文，下载后进入论文库 |
| Open Library | 补充书目检索；会标注「公开阅读」「借阅需登录」「暂无电子版」等 |
| GitHub | 社区共建的 GitHub 书库 |

找到后点「下载」即可加入藏书。默认勾选的都是**免登录**的免费来源；arXiv 和 Open Library 可按需勾选。

### 其他入口

- **书源列表**：内置「古登堡计划」「arXiv 论文」两个目录，可逐级浏览、在书源内搜索、加载更多。
- **添加书源**：右上角「添加书源」，填写 OPDS 地址（calibre-web、Calibre 内容服务器等）；需要登录的填写用户名和密码。
- **更多下载网站**：Standard Ebooks、书格、Global Grey、Faded Page、Z-Library、Anna's Archive 等在浏览器中打开，支持站内搜索的会带上你的关键词。下载文件后再导入藏书。
- **GitHub 书源列表（社区共建）**：蓝色是社区推荐的仓库，白色是你自己添加的；可以「＋ 添加仓库 owner/repo」，或点「更新清单」获取最新社区清单。
- **Calibre 书库**（桌面版）：点「连接 Calibre 书库」选择本机的 Calibre 书库文件夹，可直接浏览、阅读，或「导入全部新书」。

> 网页版受浏览器跨域限制，部分书源可能打不开。可以改用桌面版，或在「设置 → 网络 → 书源代理」填写代理地址；也可以点「浏览器下载」在浏览器里下载后再导入。

## 4. 阅读页常用工具

阅读界面、翻页、主题和阅读模式见 [02-阅读模式](02-阅读模式.md)；听书和背景音见 [03-声音](03-声音.md)；点睛阅读见 [05-点睛阅读](05-点睛阅读.md)。

### 目录

电脑点顶栏「目录」，手机点底栏「目录」。当前章节会高亮，点击即可跳转。如果书本身没有目录，轻阅会从正文**自动识别章节**生成目录，并注明「此书未自带目录, 以下章节由正文自动识别」。

### 书内搜索

点顶栏的放大镜「书内搜索」，输入关键词后回车。支持：

- 多个关键词用空格分隔；
- 「Aa」区分大小写、「\b」全词匹配、「.*」正则表达式；
- 结果按章节分组，点击跳转。用完点「清除并关闭」。

### 划线、想法与书签

1. **选中文字**，弹出浮条：选择颜色（黄 / 绿 / 蓝 / 红）即划线；点「写想法」可以划线并写下笔记；还有「AI 解读」和「从这里听」。
2. **点已有的划线**可以修改想法或「删除高亮」。
3. **书签**：点顶栏的书签图标收藏当前位置，再点一次移除。
4. **查看全部**：打开「**笔记**」面板——电脑点顶栏的「笔记」，手机点底栏的「笔记」。面板里分「划线想法」和「书签」两栏，划线按章节分组、按书中顺序排列，点击跳回原文。

### 书摘：复制、导出与金句卡片

- **复制全部**：笔记面板底部的「复制全部 · N」把整本书的划线和想法复制成纯文本，版式与微信读书「复制全部笔记」相同（`◆ 章节` / `>> 划线`），可以直接贴进聊天、备忘录或你习惯的笔记流程。
- **导出**：点「导出」选择格式——**Markdown**（Obsidian、Notion、Logseq）、**纯文本**、**JSON**（含位置、颜色、时间的完整数据）、**CSV**（Readwise 导入格式）。可以只导出某几种颜色，选择是否带章节标题、想法和划线时间；JSON 还能带上书签。可复制、保存为文件，手机上还能直接分享给其他应用。
- **单条复制**：面板里每条划线右侧的复制按钮，复制原文、想法和出处。
- **金句卡片**：选中文字后点浮条上的「金句卡片」，或在面板里点划线右侧的卡片按钮、点开划线后选「金句卡片」。共 15 套版式：弥散、毛玻璃（用书的封面）、大字报、稿纸、手账、纸卡、竖排（金句真正直排，配朱印）、书页、留白、克莱因、杂志、划线、星夜、日历、备忘录；金句按句读自动分行、字号自动铺满。比例可选 3:4（小红书）、1:1、9:16，可换底色、字体（宋体 / 黑体 / 楷体 / 得意黑及自己导入的字体）、字号，选择是否显示书名作者、章节、想法、日期和轻阅标识。手机上「保存到相册」存进相册的「LightRead」文件夹，或用「分享」直接发到微信等应用；电脑上可以保存图片或复制图片。
- PDF 的笔记面板同样支持以上功能，按页码分组。
- 以前版本的划线入库时最多保留 300 字；打开笔记面板时，轻阅会回到原文把被截断的划线补全。

### AI 助手

- 点顶栏「AI 助手」打开侧栏，问任何与这本书相关的背景知识。
- 选中文字后点「**AI 解读**」，会把选中内容发给 AI 解释。
- 默认使用**内置试用通道**，不用配置就能直接用；想换成自己的服务，见下一节。

## 5. 配置 AI 服务

AI 助手和点睛阅读默认使用**内置试用通道**：不用注册、不用 API Key，装好就能用。它经轻阅的服务器（`lightread-ai.jiangshu.ai`）转发给硅基流动的 **DeepSeek-V4-Flash** 模型，有速率限制和每日次数上限（目前每台设备每天 120 次）。

- v1.7.0 起新安装默认就是内置试用通道；以前一直停在默认设置、没填过 API Key 的用户，升级后也会自动改用它。
- 如果 AI 助手侧栏显示「30 秒接入免费 AI 模型」（比如你选了某个服务商但还没填 Key），点「**直接使用内置通道（免配置）**」就能一键切回内置通道，马上可以提问；也可以点「注册硅基流动 →」或「去设置」配置自己的服务。

想用自己的服务，打开「**设置 → AI 助手**」，在「模型服务」里选择：

| 选项 | 说明 |
|---|---|
| **内置试用通道**（内测中 · 限速） | **默认**。无需注册和 API Key，模型 DeepSeek-V4-Flash；有速率限制和每日上限 |
| 硅基流动 SiliconFlow（有免费模型） | 注册后创建 API Key 并粘贴 |
| 智谱 GLM（有免费模型） | 同上 |
| 阿里云千问、Kimi、豆包 | 填入对应平台的 API Key |
| 本地模型 (Ollama) | 使用本机运行的模型，Key 可留空 |
| OpenAI 兼容自定义 | 自填接口地址、模型和 Key |

填好后点「**测试连接**」确认可用。「获取 API Key →」会打开对应平台的申请页面。

> AI 助手只在你主动提问、解读或翻译时才会联网请求，打开书不会消耗用量。**点睛阅读**例外：你开启它之后，它会主动把正在读的章节分段发给 AI。点睛阅读默认关闭、第一次开启前会征得同意，额度也单独计算，见 [05-点睛阅读](05-点睛阅读.md#2-隐私与同意)。配置了自己的服务后，点睛阅读也会改用你的服务。

## 6. PDF 与论文阅读

PDF 有专门的阅读页，常用功能：

- **视图**：滚动 / 翻页、适高 / 适宽、单页 / 对页 / 书籍视图，缩放。默认连续滚动、适宽显示。
- **工具栏**：目录、缩略图、划线想法、页码输入框、**自动翻页**、听书、搜索、打印、幻灯片放映、全屏；「更多操作」里有另存为、打开文件所在目录、文件属性。
- **跳转后返回**：点目录或文中引用跳走后，会出现「回到刚才位置」按钮。
- **显示不正常时**：到「设置 → 阅读偏好 → PDF 渲染引擎」在 MuPDF 和 PDFium 之间切换试试。
- 扫描版 PDF 可以正常看，但没有文字层，无法划词、搜索、听书和翻译（目前不内置文字识别）。

**论文库里的 PDF** 额外提供：

- **翻译**：右侧「翻译」面板，「版式对照」或「段落列表」两种视图，滚到哪页翻哪页；也可以「划词翻译」。
- **论文 Agent**（桌面版，以前叫「AI 辅读」）：调用本机的 Pi Agent（默认）、Codex 或 Claude Code，结合整篇论文和你的笔记回答问题；含「论文十问」。在「设置 → 论文 Agent」选择引擎。
- **重排版翻译**（桌面版）：用 BabelDOC 生成保持原版排版的译文 PDF 和双语 PDF。需要额外安装约 700MB 组件，且不支持内置试用通道。

更多细节见 [论文阅读完整指南](../paper-reading.md)。

DjVu 文件使用简化的阅读页，支持翻页和适高 / 适宽。

## 7. 阅读记录

左侧「**阅读记录**」页会自动记下你每天读了多久：

- **今天**：今日阅读时长和每日目标完成度（点目标可改，0 为关闭；可选 10–120 分钟）、连续阅读天数、和昨天的比较、「继续阅读」入口。
- **本周**：每天是否达标。
- **周 / 月 / 年统计**：柱状图、总时长、日均、阅读天数、读过几本；可按「全部 / 书籍 / 论文」筛选，左右切换上一期、下一期。
- **阅读日历**：近一年或指定年份的热力图，点某一天查看当天详情。
- **里程碑**：累计阅读、阅读天数、最长连续、单日最长、读得最久的一本。

**如何计时**：阅读页在前台、且 5 分钟内有翻页等操作才计时；听书和自动翻页也计入，但距离上次手动操作超过 60 分钟后停止。当天读满 1 分钟算一个阅读日。记录只保存在你的设备上，开启同步后会在各设备间合并。

## 8. 多端同步

在「**设置 → 账号与同步**」里，有两种方式，可以只用一种，也可以同时用：

### 方式一：轻阅账号

1. 输入邮箱，点「发送验证码」。
2. 填入邮件里的 6 位验证码（10 分钟内有效），点「登录」。
3. 在每台设备上登录同一个邮箱即可。

同步**进度、笔记、书签、书单和阅读记录**；**不上传书籍文件**，另一台设备需要自己导入同一本书——轻阅会按文件内容自动匹配。不再使用时可以「退出登录」或「注销账号」（注销会删除云端的同步记录，本机书库不受影响）。

### 方式二：WebDAV 网盘（可同步书籍文件）

1. 「选择网盘」：**坚果云**（推荐 · 国内）、Koofr、自建 NAS / 网盘（Nextcloud、群晖、Alist）或其他 WebDAV。
2. 填写账号和**应用密码**（坚果云、Koofr 要用应用密码，不是登录密码；页面上有「去坚果云生成应用密码」链接）。
3. 点「连接」。验证通过后会自动开启同步并完成首次同步。

连接后可以：

- 开关「**同步书籍文件**」：关闭后只同步进度与笔记。
- 开关「**自动同步**」：启动、切到后台、退出阅读器时以及每 5 分钟自动同步。
- 点「**立即同步**」手动同步一次。
- 「更多操作」里有：测试连接、**整库备份到网盘**、**从整库备份恢复**。
- 「断开」只清除这台设备保存的账号，网盘里的数据不会删除。

## 9. 备份、迁移与存储位置

在「**设置 → 数据**」：

- **导出藏书包 / 导入藏书包**：把书籍、论文、阅读进度、标注和书源打包成一个 `.okf.zip` 文件，用于备份或换设备。注意：藏书包**不包含**应用设置、登录信息、API Key、书源密码和论文 Agent 的工作目录。
- **整库备份到网盘**：见上一节 WebDAV，适合重装或换设备时一次恢复。
- **存储位置**（桌面版）：书籍和阅读数据默认放在应用数据目录。「更改位置」可以换到别的文件夹（会复制过去，原位置数据保留）；选网盘的同步文件夹也能在多台电脑间共享。「恢复默认」回到默认位置。
- **网页版**：数据保存在当前浏览器里，**清除网站数据会一并删除**，请定期导出藏书包。

## 11. 更新

- 轻阅在启动、回到前台和恢复联网时会自动检查新版本。有新版本时，左侧边栏会出现「更新」按钮。
- 也可以手动检查：「**设置 → 关于 → 检查更新**」。
- 发现新版后点下载按钮：桌面版会下载到系统「下载」文件夹并尝试打开安装包；也可以复制链接用浏览器下载。网络不畅时会走「设置 → 网络」里的代理。
- 安装方式：macOS 把新版拖进「应用程序」替换；Windows 运行新版安装程序覆盖安装；Linux 安装新版包或替换 AppImage。覆盖安装不会删除藏书和设置，但重要资料建议更新前先导出藏书包。

## 12. Android 版说明

- Android 版目前是**实验版本**，仅提供 arm64 安装包，界面和交互仍在持续适配。
- 从 **v1.4.0** 起使用固定签名，之后的版本可以直接覆盖安装升级。
- 更早的实验版签名不统一，可能出现「签名不一致」「应用冲突」而无法覆盖安装。**这时先不要卸载旧版**：在旧版「设置 → 数据」导出藏书包（或用 WebDAV 整库备份），确认备份文件已保存到应用目录之外并且能打开，再卸载旧版、安装新版并导入。详细步骤见项目 [README](../../README.md#android实验性) 的 Android 部分。
- Android 版暂不支持离线语音模型，听书请用在线模型或系统语音。
- 「阅读模式 → 沉浸」在 Android 上会隐藏系统状态栏和导航栏（从屏幕边缘滑动可临时呼出），并保持屏幕常亮。
- 背景音在手机上切到后台时会暂停（听书正在播放时除外），回到轻阅后继续。

## 14. 常见问题

**网页版能连坚果云吗？**
可以。网页版连坚果云和 Koofr 会经轻阅同步服务中转（只转发，不保存账号密码）。如果提示「网页版暂时连不上中转服务」，稍后再试或改用桌面 / 手机 App。其他自建 WebDAV 需要服务器允许跨域访问（CORS），否则请用 App。

**WebDAV 提示账号或密码不对（401）？**
坚果云、Koofr 要填「应用密码」，不是网页登录密码。开启了两步验证的网盘通常也必须用应用密码。

**离线语音卡顿、总是「缓冲中」？**
离线模型用本机算力合成，电脑较慢时跟不上实时朗读。点面板上的「改用在线模型」，或在「引擎」里选「在线模型」。

**听书面板里没有「引擎」选项？**
网页版只支持系统语音。想用在线或离线音色，请使用桌面版。

**打字机的「淡显」看起来不太一样 / 手机上部分效果显示较旧？**
较旧的系统 WebView 不支持部分新的网页显示能力，轻阅会自动换用兼容的显示方式，功能可用但效果可能略有差异。Android 用户可以在应用商店更新「Android System WebView」或 Chrome 后再试。

**点睛阅读提示「今日内置额度已用完」？**
内置通道每台设备每天可以点睛 10 万字，第二天恢复；已经点睛过的部分不受影响，照常显示。不想等的话，在「设置 → AI 助手」填入自己的 API Key（或用本机 Ollama），就不受这个限制。见 [05-点睛阅读](05-点睛阅读.md#3-每日额度内置通道)。

**手机上一切到别的应用，背景音就停了？**
这是有意的：手机上切到后台时背景音会暂停，回到轻阅后继续（听书正在播放时不单独暂停）。离开阅读页时背景音也会停止。

**书源打不开？**
网页版受浏览器跨域限制，可以在「设置 → 网络」填写书源代理，或改用桌面版；桌面版连接不畅时可设置代理服务器。来源要求人机验证时，用浏览器下载后再导入。

**扫描版 PDF 不能划词、听书？**
扫描版只有图片、没有文字层，文字相关功能都无法使用；页面可以正常阅读。

**换了设备，页码对不上？**
页码按字号、行距和屏幕大小实时计算，不同设备会不同。阅读进度本身是按位置同步的，不受影响；需要精确定位时用百分比跳转。

**有问题怎么反馈？**
加读者微信群反馈：「设置 → 关于 → 读者群」扫码入群；二维码过期时，加页面上显示的作者微信拉你进群。报错或闪退时，先在同一处点「导出诊断日志」，把 zip 发到群里，定位会快很多。也可以到 GitHub Issues 反馈。

**诊断日志里有什么？**
应用版本、系统与 WebView 版本、内存情况，以及运行时的错误记录。日志只存在本机（桌面与 App 最多约 5MB，网页版不写文件），不会自动上传，只有你主动导出并发送才会离开设备。其中不含书籍内容、划线和设置；密钥、邮箱、用户名和书库里的文件名已去除。其他路径下的文件名可能保留，发送前可以解压查看。

**打开 PDF 提示「PDF 引擎崩溃」怎么办？**
返回后再打开一次。如果同一个文件每次都这样，点报错页上的「导出诊断日志」，再点「加读者群反馈」，把 zip 发到群里，并说明文件大小；方便的话附上文件。
