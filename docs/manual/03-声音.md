# 三、声音：听书与背景音

这一篇讲轻阅里的两种声音：

- **听书**（第 1–10 节）：把书读给你听。朗读时高亮正在读的句子，自动翻页，支持定时关闭、断点续听，还能用耳机键和锁屏控制。
- **背景音**（第 11 节）：雨声、风声、白噪音、钢琴曲这类环境声，可以单独放，也可以和听书、打字机等一起用。

> 本篇以**电子书阅读页**（EPUB、MOBI、AZW3、FB2、TXT 等）为主。PDF 的听书功能较简单，差别见文末「[PDF 听书有什么不同](#pdf-听书有什么不同)」。

---

## 1. 开始听书

**打开听书面板**

- 电脑：阅读页顶栏的「听书」图标（耳机）。
- 手机：点屏幕中间呼出工具栏，底栏「**听书**」。

**开始朗读**

点面板中间的大播放按钮（「开始听书」）。从哪里开始读，面板上会提前告诉你：

| 面板提示 | 意思 |
|---|---|
| 将从本页开始朗读 | 从当前页第一个完整的句子开始 |
| 将从上次听到的那句接着读 | 上次听到的位置就在这一页，会从那一句接着读 |

**从任意一句开始**：在正文中选中一段文字，弹出的浮条里点「**从这里听**」，就从选中位置开始朗读。（面板上也有提示：「选中文字可从任意位置开始」。）

朗读开始后：

- 正在读的句子会**高亮**显示；
- 读到页尾会**自动翻页**，读完一章自动接着读下一章；
- 全书读完会提示「全书读完了」。

> 漫画等固定版式的书不支持听书，会提示「这本书是固定版式（如漫画），暂不支持听书」。

---

## 2. 播放控制

面板中间一排按钮从左到右是：

**上一段 · 上一句 · 播放/暂停 · 下一句 · 下一段**

- 跳句、跳段时，高亮会立刻移到目标句；连续快速点几下只会重新合成一次，不会卡。
- 面板右上角有「停止」按钮（结束本次朗读）和「收起」按钮。**收起面板后朗读会继续**，屏幕上留下一个小胶囊（见第 6 节）。

### 语速

拖动「语速」滑块，范围 **0.5x–2.0x**，每档 0.1。不用停下来重新开始：正在读的这一段读完后，从下一句起按新语速朗读（面板上也有提示「改了语速或音色，当前这段读完后生效」）。

---

## 3. 朗读时翻到别处

朗读过程中，你可以照常翻页、查目录、跳到别的地方看——**朗读不会中断，也不会把你拽回去**。这时面板会提示「你翻到了别处，朗读仍在继续」，并给出两个选择：

| 按钮 | 作用 |
|---|---|
| **回到朗读位置** | 页面跳回正在朗读的那一句 |
| **从这页开始听** | 放弃原来的位置，从你现在看的这一页重新开始读 |

小胶囊和顶栏的听书标签上，也会多出一个「回到朗读位置」的小按钮（准星图标）。

---

## 4. 断点续听

停止朗读后，轻阅会记住你**听到的那一句**。下次打开这本书的听书面板时，如果当前页不是上次的位置，面板顶部会显示：

> **上次听到** 第三章 · 2 小时前「那天晚上，他终于……」　**[继续听]**

点「**继续听**」就会跳到那一句接着读。如果上次的位置正好在当前页，直接点播放就会从那一句接着读。

---

## 5. 定时关闭

面板上的「**定时**」一行可以选：

| 选项 | 效果 |
|---|---|
| 关 | 不定时（默认） |
| 15 / 30 / 60 / 90 | 这么多分钟后暂停朗读 |
| 本章 | 听完当前这一章后暂停 |

设置后，面板标题旁会显示「23:30 停止」或「听完本章后停止」。时间到了朗读会**暂停**（不是停止，可以随时点继续），并提示「已按定时停止朗读」。停止朗读时定时会自动取消。如果背景音也在播放，定时到点时它会在 30 秒内慢慢淡出并停止。

---

## 6. 进度与剩余时间

朗读时，面板顶部会显示：

- 当前章名，以及**本章还剩约多久**；
- 本章进度条；
- **预计几点听完**本章（跨过午夜会显示「预计明天 …」）；
- **全书百分比**和全书大约还剩多久。

刚开始时按常见语速估算，面板上会提示「多听几句会按你的语速自动校准」，听一会儿后时间会越来越准。

---

## 7. 小胶囊：收起面板后的控制

收起面板后，朗读继续，屏幕上会出现一个小胶囊：

- **工具栏隐藏时**（沉浸阅读），胶囊默认停在**页面顶部的页眉留白处**，不挡正文。它显示「朗读中 / 已暂停 · 本章还剩多久」，旁边有暂停/继续和停止按钮。
- **工具栏显示时**，胶囊会收进**顶栏中间**，变成一个小标签，显示本章剩余时间和暂停/继续按钮。
- **点一下**胶囊：重新展开听书面板。
- **拖动**胶囊：可以放到屏幕任何位置，轻阅会记住这个位置（拖过之后，工具栏出现时它也留在原处）。
- **双击**胶囊：回到默认的顶部位置。
- 缓冲时胶囊会显示「缓冲中…」。

---

## 8. 耳机键、媒体键与锁屏

在支持系统媒体控制的平台上，听书开始后会出现在系统的「正在播放」里（显示章名、作者和书名），可以用耳机线控、蓝牙耳机、键盘媒体键或锁屏控件操作：

| 按键 | 作用 |
|---|---|
| 播放 / 暂停 | 播放 / 暂停 |
| 下一曲 / 上一曲 | 下一段 / 上一段 |
| 快进 / 快退 | 下一句 / 上一句 |
| 停止 | 停止朗读 |

> 不同系统、浏览器对媒体控制的支持程度不同，个别按键可能不响应。

## 9. 选择声音：几种引擎

面板下方「**引擎**」一行有这些选项：

| 引擎 | 需要联网 | 在哪里可用 | 特点 |
|---|---|---|---|
| **在线模型** | 是 | 桌面版、Android 版 | 微软神经网络音色，自然流畅，**默认引擎** |
| **本地模型** | 否（只需下载一次语音包） | 桌面版、安卓版 | Kokoro 离线模型，用**本机算力**合成 |
| **系统** | 否 | 所有版本 | 操作系统自带语音，音质取决于系统 |
| **API** | 是 | 桌面版、App | 用自己的 MiniMax、豆包账号合成，音色更丰富，按字数收费（见 9.4） |
| **SAPI** | 取决于语音 | 仅 Windows 桌面版 | 这台电脑注册的 SAPI 5 语音（见 9.5） |

> **网页版**只能使用系统语音，面板上不会显示引擎选择。

### 9.1 在线模型

- 默认音色：**曉臻 · 台湾腔女声**（音色列表里标着「(默认)」），升级前一直用旧默认音色（晓晓）的用户也会自动换成它；语气柔和，适合长时间听书。
- 「音色」下拉框里还有：晓晓（女声温暖）、云希（男声阳光）、云健、晓伊、云扬、云夏等普通话音色；曉雨、雲哲等台湾腔音色；粤语、东北话、陕西话音色；以及英语、日语音色。共 20 个。
- 需要联网。连不上时会自动改用系统语音，并提示「所选音色暂不可用，已改用系统语音」。

### 9.2 本地模型（离线）

适合没有网络、或者不想把文字发到网上合成的时候。

1. 引擎选「**本地模型**」。
2. 第一次使用时点「**下载离线语音包 (~310MB)**」，等待下载和解压完成（会使用「设置 → 网络」里的代理）。完成后提示「离线语音包已就绪」。
3. 在「音色」里选择。共 103 个中英文音色，默认是一个**普通话女声**（标着「· 默认」）。可以点「**试听**」先听一句。
4. 首次加载模型约需 10–20 秒，打开听书面板时就会在后台提前加载。

**要知道的**

- 离线模型使用**这台电脑自己的算力**合成语音，电脑较慢时可能卡顿。鼠标悬停在「本地模型」上会提示「使用本机算力，无需联网；电脑较慢时可能卡顿」，面板下方也有同样的说明。
- 如果听起来断断续续、经常出现「缓冲中」，说明本机算力跟不上实时朗读。轻阅检测到连续卡顿时会提示「本机算力跟不上实时朗读，推荐改用在线模型」，点「**改用在线模型**」即可一键切换。
- 离线音色**都是普通话**，暂时没有台湾腔，所以离线默认是普通话女声，而在线默认是台湾腔女声。
- 安卓版也能用离线模型（听书面板 → 音色 → 离线 → 下载语音包）。合成靠手机自己的处理器，较旧的手机会跟不上朗读而出现停顿，界面会提示改用在线语音。iPhone / iPad 暂不支持。

### 9.3 系统语音

- 「音色」里可以选「自动 (中文优先)」或系统提供的任一语音。
- macOS 用户可以在「系统设置 → 辅助功能 → 朗读内容」下载更好听的中文音色，再回到轻阅选择。

> 换引擎、换音色、调语速，朗读都不用停下来：正在读的这一段读完后，从下一句起按新设置朗读。

---

### 9.4 API 语音（自带 Key）

想要更接近真人主播的声音，可以用自己的 MiniMax 或火山引擎豆包语音账号：在听书面板把语音切到「API」，选服务商，粘贴 API Key，再选音色并试听。网页版不提供这一项。

- 文字会发送给你选的服务商，费用由服务商按字数收取。轻阅只为听书预取不多的内容，但预取过又跳走的部分同样计费。
- MiniMax 的国内站和国际站 Key 不通用。豆包新版控制台只需要 API Key；旧版控制台把 Access Token 填在 Key 一栏，另填 App ID。
- 目录外的音色和复刻音色，选「自定义音色 ID」后填写。
- 服务商的语速上限是 2×，更高的语速按 2× 合成。
- Key 只存在本机；只有打开「同步密码与密钥」时才会随同步带到其他设备。

### 9.5 SAPI 5 语音（Windows）

Windows 桌面版的「SAPI」列出这台电脑注册的 SAPI 5 语音。系统语音和第三方语音都可以用；安装第三方的 [NaturalVoiceSAPIAdapter](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter) 后，Windows 11「讲述人」的自然语音也会出现在这里。轻阅是 64 位应用，需要安装适配器的 64 位版本。

## 10. 听书和其他功能的关系

- **与打字机互斥**：开始听书会自动退出打字机模式；开始打字机会暂停听书。详见 [02-阅读模式](02-阅读模式.md#55-带读之间的关系)。
- **可以和歌词一起用**：听书时打开歌词，歌词会跟着朗读一行一行走；在歌词里点另一行，听书就从那一句开始读。详见 [02-阅读模式](02-阅读模式.md#534-和听书一起用)。
- **和背景音一起用**：听书出声时背景音会自动压低，定时关闭到点时背景音也跟着慢慢淡出，见第 11 节。
- **计入阅读时长**：听书时间计入「阅读记录」，但距离你上次手动操作超过 60 分钟后不再计时（防止睡着后一直累计）。

## 11. 背景音

读书时放一点雨声、风声或钢琴曲，盖住周围的杂音。背景音**默认关闭**，轻阅从不在启动或打开书时自动播放；它只记住你上次选的场景和音量。

> 说实话：有歌词的音乐和听得清的人声最容易打断阅读，所以这里只有环境声和纯音乐（面板底部也这么写）。研究上，背景噪音对有的人有一点帮助、对有的人反而是干扰，因人而异。我们不承诺它能让你更专注，觉得分心就关掉。

### 11.1 打开背景音面板

阅读页**顶栏**的「背景音」按钮（电脑和手机上都在顶栏）。正在播放时按钮会高亮，并带一个小圆点。电脑上面板浮在顶栏下方，手机上是底部抽屉。**关掉面板不影响播放。**

背景音目前只在电子书阅读页提供，PDF 和论文阅读页没有。

### 11.2 选一个场景

点场景卡片就开始播放；再点一次正在播放的场景就停止。

**本机合成 · 离线可用**（4 个）：由轻阅在你的设备上实时生成，**不用下载任何文件**，断网也能用，而且永远不会循环重复。

| 场景 | 声音 |
|---|---|
| **雨夜书房** | 细雨，衬一层柔和的铺底音（默认场景） |
| **林间风声** | 起伏的风，远处偶有轻响 |
| **专注噪音** | 平稳的噪音，可在下面的「颜色」里选**白噪 / 粉噪 / 棕噪**（默认粉噪） |
| **夜曲铺底** | 缓慢变化的柔和和声 |

**实地录音 · 按需下载**（7 个）：真实录音，第一次点的时候才下载，下载完存在本机，之后离线也能播放。分组标题上会显示全部下载大约多大。

| 场景 | 声音 | 大约大小 |
|---|---|---|
| **窗边雨** | 实录的绵长雨声 | 0.5 MB |
| **咖啡馆** | 远处的交谈与杯碟声，处理过，听不清说话内容 | 0.5 MB |
| **壁炉** | 柴火噼啪，衬一点雨 | 0.7 MB |
| **林间鸟鸣** | 春日午后的树林 | 0.6 MB |
| **海边** | 平缓的海浪 | 0.5 MB |
| **夏夜虫鸣** | 后院的蟋蟀 | 0.6 MB |
| **钢琴夜曲** | 萨蒂《裸体歌舞曲》第 1 号、肖邦《夜曲》Op. 9 No. 2，公有领域录音 | 5.5 MB |

七个全部下载约 9 MB（不支持 Opus 格式的系统改下 AAC 版本，约 10 MB；轻阅会自动选择）。表里是 Opus 版本的大小，面板上显示的是你的设备实际要下载的大小。

- 下载时卡片上显示「下载中 N%」，完成后显示「已下载」；失败时显示「下载失败，点按重试」。
- 已下载、且没在播放的场景旁边有一个删除按钮（「删除下载」），可以随时删掉释放空间。
- 下载会校验文件完整性。录音托管在轻阅自己的服务器上。

### 11.3 音量、定时和其他选项

| 选项 | 说明 |
|---|---|
| **播放 / 停止** | 音量左边的按钮。停止时会在 1–2 秒内淡出 |
| **音量** | 0–100%，默认 30% |
| **定时** | 关 / 15 / 30 / 60 / 90 分钟。到点前 30 秒开始淡出，到点停止；面板上显示「N 分钟后淡出停止」 |
| **听书时自动降低** | 默认开。听书出声时背景音自动压低到原来的约四分之一，暂停或停止听书后恢复；面板标题旁显示「听书中，已压低」 |
| **分层音量** | 点「分层音量 · 场景名」展开，每个场景由几层声音组成（比如雨夜书房 = 雨 + 铺底音），可以分别调。有的录音场景还附带一层默认音量为 0 的合成声（比如窗边雨的铺底音、咖啡馆的雨），想要可以自己调上来。调过的音量会被记住 |

### 11.4 什么时候会自动停

- **离开阅读页**（回到书架、关闭这本书）时背景音淡出停止。它属于阅读场景，不会在书架上继续响。
- **手机上切到后台**（Android / iOS）时背景音会暂停，回到轻阅后接着放；但**听书正在播放时**，背景音不单独暂停，跟着听书的后台策略走。电脑上切到别的窗口不会暂停。
- **听书的定时关闭**到点时，背景音在 30 秒内淡出停止（见第 5 节）。
- 当前环境不支持网页音频时，会提示「当前环境无法播放背景音」。

### 11.5 声音来源与许可

面板底部的「**声音来源与许可**」会打开一份清单（[docs/ambient-sources.md](../ambient-sources.md)），逐条写明每段录音的作者、出处和许可：

- 四个合成场景没有用到任何录音文件，由轻阅的代码实时生成。
- 七个录音场景的素材全部是 **CC0 1.0**（公有领域贡献），可以自由使用和再分发。萨蒂和肖邦的作品早已进入公有领域，所用的两份钢琴录音也由演奏者或发布方以 CC0 放弃了权利。
- 轻阅只收 CC0、公有领域或 CC BY 许可的声音，不收禁止商用、禁止演绎等限制性许可的素材。

## PDF 听书有什么不同

PDF（包括藏书里的 PDF 和论文）使用另一套更简单的听书控制条。在 PDF 阅读页顶部工具栏点「**听书**」打开：

| 功能 | 电子书 | PDF |
|---|---|---|
| 开始 / 暂停 / 继续 / 停止 | ✓ | ✓ |
| 语速、引擎、音色 | ✓ | ✓ |
| 从哪里开始 | 本页、断点或选中文字 | 从**当前页**开始，一页一页往下读，读完自动翻页 |
| 句子高亮、跳句 / 跳段 | ✓ | — |
