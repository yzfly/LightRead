# 隐私政策

更新日期：2026-11-14

轻阅（LightRead）是开源、本地优先的电子书与论文阅读器，适用于 Windows、macOS、Linux、Android、iOS 与网页版。这份说明讲清楚轻阅在你的设备上保存什么、什么时候会联网、联网时发出去的是什么。源码公开在 [GitHub](https://github.com/yzfly/LightRead)，下面每一条都能在代码里核对。

## 一句话

书、阅读进度、划线、笔记和设置默认只保存在你的设备上。轻阅没有广告，不接入第三方统计或追踪工具，也不出售任何数据。只有你用到下面列出的联网功能时，才会把完成该功能所需的内容发给对应的服务。

## 保存在你设备上的内容

- 你导入的书和论文文件、封面、书目信息。
- 阅读进度、阅读时长与每日阅读记录、划线、笔记、书单。
- 设置，包括你填写的 WebDAV、私人书库（OPDS）、AI 服务的地址与密钥。
- 诊断日志：应用出错时记录在本机，用于排查问题。日志写入和导出时都会去掉网址参数、密钥、密码、令牌等敏感信息，不记录书籍正文、划线和设置内容。**日志不会自动上传**，只有你在「关于」页主动导出并发给我们时，我们才能看到。

卸载应用会删除这些内容（iOS 与 Android 由系统负责清理应用数据）。

## 轻阅账号（可选）

不登录也能使用全部阅读功能。登录后用于多台设备之间同步与互传：

- **邮箱**：用于发送登录验证码（验证码邮件经 Resend 发出）。
- **同步记录**：书目信息（书名、作者、格式、加入时间等，不含书籍文件）、阅读进度、阅读时长、划线与笔记、书单，以及选择同步的设置。私人书库的地址与账号密码会随同步保存，以便在其他设备上使用。你标为「私密」的书不参与同步。
- **互传**：你主动发送到其他设备的文字、链接或文件，保存 7 天后自动删除。
- **登录设备**：设备名称与最近使用时间，90 天未使用的记录自动删除。

账号数据保存在 Cloudflare（服务地址 `sync.jiangshu.ai`）。你可以在设置的账号页**注销账号**，注销后账号、全部登录会话、同步记录和互传内容会立即一并删除。

如果改用自己的 WebDAV（如坚果云）同步，数据只在你的设备与你的 WebDAV 之间传输，我们收不到。网页版因浏览器限制，坚果云和 Koofr 的请求会经我们的服务原样转发，不做保存。

## 匿名使用统计

为了解有多少人在用、哪些版本还在使用，应用每天最多发送两次匿名「心跳」，只包含：

- 首次启动时随机生成的安装 ID（与账号、邮箱、设备硬件都无关）；
- 平台、应用版本、界面语言；
- 当天是否打开过书（不含书名、内容或阅读时长）。

服务端不保存 IP 地址和浏览器标识，按天记录的明细 90 天后合并为按平台、版本的总数。

## 联网功能会发出的内容

下列功能只在你使用时才联网，发送的内容仅用于完成该功能：

| 功能 | 发送到 | 发送的内容 |
|---|---|---|
| 在线语音听书 | 微软 Edge 朗读服务 | 正在朗读的文字 |
| API 语音（MiniMax、火山引擎豆包） | 你选择的服务商，使用你自己的 API Key | 正在朗读的文字；费用由服务商按字数收取 |
| AI 助手、点睛阅读、论文 Agent | 你配置的 AI 服务；或轻阅内置的试用通道（经我们的服务转发给硅基流动等模型服务商） | 你的提问和相关的书中段落；内置通道另带一个随机设备 ID 用于每日额度 |
| 划词翻译 | 轻阅的翻译服务（需登录，经我们的服务转发给模型服务商） | 选中的文字与目标语言；按账号统计每日次数 |
| 书源与论文搜索 | 你选择的公共书库、OPDS 书库、arXiv 等 | 搜索词；下载时的书籍地址 |
| 下载背景音、读者群二维码 | 轻阅的静态资源服务 | 普通的下载请求 |
| 下载本机模型、离线语音包 | Hugging Face、ModelScope、GitHub、GitCode 等 | 普通的下载请求 |
| 检查更新、下载页 | GitHub、GitCode | 普通的网页请求 |

经我们转发的 AI 与翻译请求不保存提问和回答内容，只为限额按设备或账号计数。第三方服务如何处理收到的内容，以它们各自的隐私政策为准。

选择本机模型（离线翻译、本机对话、离线语音）时，处理全部在你的设备上完成，不联网。

## 系统权限

- **相册（仅添加）**：保存金句卡片时使用，不读取你的照片。
- **文件**：只访问你主动选择或「用轻阅打开」交给轻阅的文件。

轻阅不使用定位、通讯录、相机和麦克风。

## 儿童

轻阅不面向儿童单独收集任何信息，也不要求填写年龄。

## 变更与联系

这份政策变更时会更新上方日期，并在版本说明里提及。有问题请在 [GitHub Issues](https://github.com/yzfly/LightRead/issues) 提出，或在应用「关于」页加入读者群联系作者。
